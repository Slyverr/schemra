# Changelog

All notable changes to Schemra will be documented here. Entries summarize
changes for users rather than listing commits.

The format follows [Keep a Changelog 2.0.0](https://keepachangelog.com/en/2.0.0/),
and releases follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- A Rust language toolchain for parsing, validating, formatting, compiling, and
  rendering Schemra diagrams and animated scenarios.
- A command-line interface, language server, and WebAssembly APIs backed by the
  same compiler and rendering engine.
- Schemra Studio for editing local projects, previewing diagrams, and playing
  scenarios in a browser.
- A static Studio build that can be hosted on a static web server.
- An example project that demonstrates the current visual and scenario syntax.
